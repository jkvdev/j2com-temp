# J2Store Joomla Plugin Repository

This repository contains the core files for the J2Store Joomla plugin, a powerful and customizable eCommerce solution for Joomla CMS. It includes all necessary components, modules, and scripts related to J2Store, enabling users to add eCommerce functionality to their Joomla websites.

## Repository Structure

The repository is organized as follows:

- **/administrator/components/com_j2store/**: Contains the backend components for managing J2Store settings, products, orders, and other administrative tasks.
- **/components/com_j2store/**: Includes the frontend components that handle the display of products, cart, checkout, and other eCommerce features for users visiting the site.
- **/libraries/joomla/j2store/**: Contains library files that are used by both the frontend and backend of the J2Store plugin, providing essential functionality.
- **/media/j2store/**: Houses assets like images, stylesheets, and JavaScript files that are required for the proper functioning of J2Store on the frontend.
- **/plugins/system/j2store/**: The system plugin directory that is responsible for initializing and managing J2Store’s system-level tasks within Joomla.

## Key Features

- **Admin Management**: Includes an intuitive admin interface for managing products, orders, customers, and other eCommerce functions directly from the Joomla backend.
- **Customizable Product Display**: Provides multiple options for displaying products and categories on the frontend, including grid and list views.
- **Advanced Cart and Checkout**: Offers a fully-featured shopping cart and secure checkout process with various payment gateway integrations.
- **Custom Fields**: Allows you to add custom fields to products and checkout forms for a tailored eCommerce experience.
